# tui-input-chrome Specification

## Purpose

Provide a visually distinct input area in the TUI so the prompt field is clearly separated from the transcript above it.

## Requirements

### Requirement: Input area is visually bordered

The system SHALL render the prompt input area with a visible border so it is clearly distinguished from the scrolling transcript.

#### Scenario: Input area has a visible border

- **WHEN** the TUI is displayed
- **THEN** the prompt input area is enclosed in a visible border that separates it from the transcript
